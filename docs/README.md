# Documentación del Proyecto - Archivo Digital

Bienvenido al directorio de documentación técnica del proyecto **Archivo Digital** para la cátedra de Diseño y Desarrollo de Sistemas Organizacionales (DDSO - UNSAM).

## Estructura de Documentación

| Documento | Descripción |
|---|---|
| [`api.md`](api.md) | Especificación de la API REST, endpoints, DTOs de request/response y códigos de estado HTTP. |
| [`test.md`](test.md) | Estrategia de pruebas, convenciones, matriz de casos de prueba y comandos de ejecución. |
| [`diagramas/`](diagramas/README.md) | Espacio centralizado para los diagramas requeridos por la cátedra. |

### Diagramas de Diseño y Arquitectura

* [**Diagrama de Arquitectura**](diagramas/arquitectura.md): Vistas C4 (Contexto Nivel 1 y Contenedores Nivel 2) y modelo de capas.
* [**Diagrama de Clases**](diagramas/clases.md): Diagrama de clases de dominio, entidades, atributos, métodos y relaciones.
* [**Diagrama Entidad-Relación (DER)**](diagramas/der.md): Modelo de datos relacional, tablas, claves primarias/foráneas y cardinalidades.
* [**Diagramas de Secuencia**](diagramas/secuencias.md): Flujos de interacción entre capas para consultas, mutaciones de negocio y manejo de errores.
